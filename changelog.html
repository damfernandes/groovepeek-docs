Changelog

Both extensions are versioned independently. This page is the release history for each.

GroovePeek

1.2.0 Pending store review

Added

  • ×2 and ÷2 buttons for octave errors. The characteristic tempo error is an octave — half or double the real value, which happens when a busy guitar or a strong off-beat looks more periodic than the beat itself. Two buttons under the number now correct it directly. They only change the number on screen: GroovePeek keeps measuring what it measured, nothing is remembered between sessions, and the correction is dropped when the song changes.
  • The beat pulse is phase-locked. It now lands on the song's actual beats rather than merely running at the right rate. Each analysis pass reports the timestamp of a real beat and the popup re-anchors to it, nudging small errors, snapping when it drifts past a quarter of a beat, and falling back to free-running when the anchor goes stale.

Fixed

  • Song changes were missed on YouTube tabs showing a notification count. A title like (3) Song Name - YouTube did not match the previous title, so the reading did not reset when the track actually changed. The count prefix is now ignored.

Faster

  • The magnitude spectrum is computed with a real-input FFT, packing the samples into a half-size complex transform.
  • FFT cost in the detection loop cut by 7.8×.
  • The analysis cadence is pinned at 2 seconds. It previously slept a flat interval after each analysis, which made the real period depend on how fast your machine was — and quietly retuned the confidence trajectory along with it.

PitchPeek

1.1.0 Pending store review

Added

  • It now says when it cannot measure. Some material has no tuning reference to find at all — percussion, spoken word, field recordings, heavily processed sound. Previously that looked identical to still warming up: a spinner and a dash, indefinitely. Once PitchPeek has listened long enough and still cannot place the pitch, it says so and stops the spinner. No number is shown and no confidence is invented; it simply stops pretending to still be working.

Faster

  • The same real-input FFT applies to PitchPeek's larger analysis window.
1.0.0 First public release
  • PitchPeek's first release on the Chrome Web Store.
