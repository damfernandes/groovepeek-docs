Changelog

Both extensions are versioned independently. This page is the release history for each.

GroovePeek

1.2.0 Pending store review

Added

  • ×2 and ÷2 buttons to fix a reading that lands an octave off. Display only — it does not change what the detector measured, and it resets with the song.
  • The beat pulse now locks to the song's actual beats, not just its tempo.

Fixed

  • Track changes were missed on YouTube tabs showing a notification count, like (3) Song Name.

Faster

  • Much cheaper analysis, and a steady 2-second update rate on any machine.
1.1.0 First public release
